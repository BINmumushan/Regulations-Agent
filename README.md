# 大数据相关政策知识问答 Agent

Agent 默认以苏州/江苏为主要语境：未点名外地地区、未要求横向比较时，不会引入其他地区政策；需要对比时（如“苏州和上海有什么区别”）或点名上海、山东、深圳等外地地区时，才会检索对应外地文档。

知识库按政策层级分区（国家/省级/市级/园区/其他地区），提问时可以指定层级只检索该层级，也可以点名具体文件（如“检查一下《大数据局反馈》”）只查该文件。

除了普通问答，还支持**结构化解读/报告**：问题里出现“解读、报告、汇报、提纲、要点、主要内容”等词时，自动按“政策名称与基本信息 / 背景与总体目标 / 适用对象 / 主要内容与重点任务 / 支持措施 / 申报要求与流程 / 实施期限与保障措施 / 依据文件与来源”组织输出，每个要点标注（《文件名》）来源；没有知识库依据的小节会省略，不会编造。

## 目录结构

```text
Regulations-Agent/
├── kb_agent/            # 核心代码：配置、读取、入库、问答、联网搜索、FastAPI 服务
├── data/pdfs/           # 把你的文档（PDF/TXT/MD/CSV/DOCX/DOC/PPT/PPTX/WPS/XLSX 等）放到这里
├── data/vectorstore/    # FAISS 向量库（自动生成，当前 9807 个片段）
├── data/ocr_cache/      # 扫描 PDF / 图片的 OCR 缓存（自动生成）
├── ingest_pdfs.py       # 入库入口
├── ask.py               # 命令行问答入口
├── run_server.py        # HTTP 服务入口
├── self_check_learning.py  # 全量自检：核对所有文档是否完整入库
├── tests/               # 本地测试（不需要真实 API Key）
├── requirements.txt
├── .env.example
└── .tools/              # demo 隧道工具 cloudflared 及日志（内部试用用）
```

# 政策知识问答 Agent

一个基于 LangChain 的严格知识库问答 Agent：把 PDF（含扫描件自动 OCR）、TXT/MD、CSV、DOCX/DOC、PPT/PPTX、WPS、Excel、JPG/PNG 图片（自动 OCR）等文档切块后写入本地 FAISS 向量库，回答问题时只依据知识库内容作答；知识库中没有明确答案时，会委婉说明暂时无法回答（例如“我还不懂这些，你可以换个问法再问一次”），且不显示来源、不会要求你上传或补充文档。未答时会追加询问“需要我帮你联网搜索相关的答案吗？”，只有你同意后才会联网检索公开网页，联网答案会明确标注“以下内容来自联网搜索，并非官方文件内容，仅供参考，请谨慎辨别”。

Agent 默认以苏州/江苏为主要语境（含园区、苏州工业园区等）：未点名外地地区、未要求横向比较时，不会引入其他地区政策；需要对比时（如“苏州和上海有什么区别”）或点名上海、山东、深圳等外地地区时，才会检索对应外地文档。

知识库按政策层级分区（国家/省级/市级/园区/其他地区），提问时可以指定层级只检索该层级，也可以点名具体文件（如“检查一下《大数据局反馈》”）只查该文件。当前 `data/pdfs/` 中 **205 份文档已全部入库**（磁盘 215 个文件，含 10 个跨目录同名副本去重），向量库共 **9807 个文本片段**。

除了普通问答，还支持**结构化解读/报告**：问题里出现“解读、报告、汇报、提纲、要点、主要内容”等词时，自动按“政策名称与基本信息 / 背景与总体目标 / 适用对象 / 主要内容与重点任务 / 支持措施 / 申报要求与流程 / 实施期限与保障措施 / 依据文件与来源”组织输出，每个要点标注（《文件名》）来源；没有知识库依据的小节会省略，不会编造，仍严格遵守“只能依据知识库”的约束。

同时支持**多轮对话**：网页采用聊天型界面，第二个问题可以承接第一个问题的回答（例如先问“数字孪生是什么？”，再追问“园区对它有什么期望吗？”时，会先把“它”解析为“数字孪生”再检索；同一句话里抛出多个问题时也支持，例如“数字孪生是什么？园区对它有什么期望吗？”；也可以先问某政策再追问“那它呢”“申报条件是什么”）；承接问题会先做指代替换、再结合历史改写后检索，未命中新内容时也可基于上一轮已确认的回答继续作答，但所有内容仍然只来自已有资料。

网页交互也已打磨：左侧边栏保存多段对话，点“新建对话”不会清掉当前对话，可以随时切回或删除；回答里的来源默认收起，点“来源 (N)”下拉箭头才展开；委婉未答时不提供下载按钮；下载的整段对话 PDF 不显示来源，也不会包含“未知问题 + 委婉回答”这类问答组。回答措辞面向普通用户，不会出现“知识库”等后台术语，需要说明依据时使用“根据我的理解”“从已有资料看”“据了解”等表达。对话历史保存在浏览器本地，刷新页面不丢失。

## 通用逻辑（不写死文件名）

- 文档发现只扫描 `data/pdfs/`，支持的扩展名统一由 `kb_agent/loaders.py` 里的 `SUPPORTED_SUFFIXES` 定义；入库、上传校验、全量自检都引用同一常量，新增格式只需改一处。
- 文件名只作为片段元数据 `source` 使用，业务逻辑不依赖具体文件名；用户用《书名号》点名文件时，由 `qa.detect_target_sources()` 自动匹配知识库文件名。
- 政策层级从父目录名（如 `01国家政策`）自动识别为 `tier`，新增层级只需新建对应目录。
- 测试夹具文件名统一集中在 `tests/test_pipeline.py` 顶部的常量区，新增或改名测试文件时只改常量，不散落硬编码。
- `self_check_learning.py` 自动遍历 `data/pdfs/` 并逐份比对原始读取、切块结果和向量库，新增文件后可直接运行做完整性自检。

## 快速开始

1. 安装 Python 3.10 或更高版本（项目已按 Python 3.12 验证）。
2. 在项目根目录创建虚拟环境并安装依赖：

   ```powershell
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   python -m pip install -r requirements.txt
   ```

   注意：如果 PowerShell 里的 `python` 不是这个虚拟环境，请始终用 `.\.venv\Scripts\python.exe` 代替 `python` 运行下面的命令，例如：

   ```powershell
   .\.venv\Scripts\python.exe ingest_pdfs.py
   ```

3. 复制 `.env.example` 为 `.env` 并填入模型 API 配置。当前项目默认接 DeepSeek，`.env` 示例：

   ```env
   OPENAI_API_KEY=sk-你的DeepSeek密钥
   OPENAI_BASE_URL=https://api.deepseek.com/v1
   LLM_MODEL=deepseek-v4-flash
   EMBEDDING_PROVIDER=local
   EMBEDDING_MODEL=BAAI/bge-small-zh-v1.5
   # 内部 demo 试用版访问密码（留空关闭密码门；具体说明见“Demo 试用版”小节）
   DEMO_PASSWORD=
   ```

   DeepSeek 只提供聊天接口，不提供 embedding 接口，所以向量化使用本机 `fastembed` 中文模型。首次建库会自动从 `hf-mirror.com` 下载约 100MB 模型，只需要一次。

4. 把你的文档放进 `data/pdfs/`（只有这个目录里的文件会进知识库）。支持 `.pdf`（文字版或扫描版）、`.txt`、`.md`、`.csv`、`.docx`、`.doc`、`.pptx`、`.ppt`、`.wps`、`.xlsx`、`.xlsm`、`.xls`、`.jpg`、`.jpeg`、`.png`；扫描版 PDF 和图片会由本地 RapidOCR 自动识别文字（长图会自动分条带识别）。`.doc`/`.ppt`/`.wps` 会优先用本机 Word/WPS COM 精确读取，没有 Office 或无法启动 COM 时自动回退到内置解析。然后建库：

   ```powershell
   .\.venv\Scripts\python.exe ingest_pdfs.py
   ```

   新增文件后再次运行会自动追加；想完全重建请加 `--rebuild`。

   扫描版 PDF 的识别结果会按页缓存在 `data/ocr_cache/`，图片识别结果同样缓存，中断后重跑会接着已完成页面继续；页数很多的扫描件会自动多进程并行识别。OCR 分辨率由 `PDF_OCR_DPI` 控制（默认 200）。`--rebuild` 会按当前 `PDF_OCR_DPI` 重新识别扫描页，缓存按 DPI 分开保存；若要复用已有缓存，重建时保持相同 DPI。

   建议按政策层级分区存放：`data/pdfs/01国家政策`、`02省级政策`、`03市级政策`、`04园区政策`、`05其他地区政策`。文件放根目录也能入库，但没有层级标签。提问时带上“国家政策/省级/市级/园区/其他地区”只会检索对应层级；不带层级词时默认在国家/江苏/苏州/园区范围内检索，不会引入其他地区政策。问题里用书名号点名文件（如“检查一下《大数据局反馈》有没有答案”）时，只检索匹配的文件。问山东、厦门、北京、上海、济南、深圳、宁波、萧山、青岛等具体外省/外地地区，或问“苏州和上海有什么区别”等横向比较问题时，会跨层级检索并引入外地文档，避免漏掉暂存在其他层级目录中的地区文件。

5. 问答：

   ```powershell
   .\.venv\Scripts\python.exe ask.py "退货时间是几天？"
   .\.venv\Scripts\python.exe ask.py          # 不带问题进入交互模式
   ```

   模型可在 `.env` 中切换：`deepseek-v4-flash` 更快，`deepseek-v4-pro` 更强。

   不想记长命令的话，项目里已经提供一键脚本：

   ```powershell
   .\run_ingest.bat
   .\run_ask.bat "你的问题"
   .\run_server.bat
   ```

## HTTP 服务

```powershell
.\.venv\Scripts\python.exe run_server.py --port 8000
```

- 浏览器打开 `http://127.0.0.1:8000`，直接在网页里输入问题即可问答。
- 页面为聊天型界面：用户气泡在右、助手气泡在左，输入栏置底，回车发送、Shift+回车换行；左侧边栏保存多段对话，点“新建对话”会保留当前对话并开新对话，可随时切换或删除，对话历史保存在浏览器本地。委婉未答下方有“联网搜索”按钮，点击即可联网搜索；联网回答带“联网搜索”徽标和免责声明。
- 页面标题为“政策知识问答”，回答内容用 Markdown 排版（标题、加粗、列表、引用、代码、表格）。回答里的来源默认收起，点“来源 (N)”下拉箭头展开。欢迎语、第一轮回答以及委婉未答不显示下载按钮；后续正常回答右下角有隐蔽的下载图标，点击会把从对话开始到当前回答为止的全部聊天记录导出为一份中文 PDF（PDF 不显示来源，且会自动剔除委婉未答的问答组）。
- 若 `.env` 配置了 `DEMO_PASSWORD`，打开网页会先显示密码门：密码必须手打（不支持粘贴），同一浏览器最多错 3 次，第 3 次后锁定 3 分钟，错误时会提示“密码错误，还剩 N 次机会。”；前端会自动携带 `X-Demo-Password` 和 `X-Demo-Client-Id`。demo 专用设置见下文“Demo 试用版”小节。
- 服务由你自己在 PyCharm 或终端启动；如果 8000 端口已被占用，用 `--port` 换一个端口。
- `POST /ask`，请求体：`{"question": "...", "history": [{"role": "user", "content": "..."}, ...]}`（`history` 可省略），返回 `{"answer": "...", "sources": [...], "unknown": false, "web": false}`；`unknown=true` 表示委婉未答，`web=true` 表示该答案是联网搜索整理结果（sources 为空，答案自带免责声明）。
- `GET /auth/status` 返回 `{"enabled": ..., "locked": ..., "retry_after": ...}`；`POST /auth/check` 用 `{"password": "..."}` 校验密码。密码启用时 `/ask`、`/export-pdf`、`/upload` 需要 `X-Demo-Password` 请求头，密码错误返回 401，3 次错误后锁定期间返回 429。
- `POST /export-pdf`，单条请求体：`{"question": "...", "answer": "...", "sources": [...]}`；整段对话请求体：`{"messages": [{"role": "user", "content": "..."}, {"role": "assistant", "content": "...", "sources": [...], "unknown": false}]}`；`unknown=true` 的回答及其对应的提问会自动过滤，返回 PDF 附件下载。
- `POST /upload`，用 multipart 表单上传文档（支持上面列出的全部格式），上传后自动入库（网页页面已移除上传入口，文档统一放到 `data/pdfs/` 后入库）。
- `GET /health` 检查服务状态。

示例：

```powershell
Invoke-RestMethod -Method Post -Uri http://127.0.0.1:8000/ask -ContentType "application/json" -Body '{"question": "退货时间是几天？"}'
```

## 严格作答机制

1. 检索时按相似度阈值过滤，低于 `SCORE_THRESHOLD` 的内容不会进入回答，此时返回委婉的未答说明（例如“我还不懂这些，你可以换个问法再问一次。需要我帮你联网搜索相关的答案吗？”），且不显示来源、不会要求用户上传或补充文档。
2. 提示词明确要求只使用“知识库内容”作答，禁止编造和推测；同一文件可能被拆成多个片段，必须综合所有相关片段，未在知识库中明确出现的奖项、数字、条款不得补充。
3. 模型温度固定为 0，降低自由发挥的概率。
4. 提问时若包含层级词（如“市级”“国家政策”），只在对应层级文档中检索；未指定时默认在国家/江苏/苏州/园区范围内检索，不引入其他地区政策。问具体外省/外地地区（如山东、深圳、厦门、青岛等）或问横向比较（如“苏州和上海有什么区别”）时跨层级检索，避免漏掉暂存在其他层级目录中的地区文件。
5. 问题里用《书名号》点名文件时，自动匹配知识库文件名并只在这些文件中检索；没有答案时返回委婉的未答说明。
6. 每个片段都带来源标签；命中反馈类短文档时整文件片段一起进入上下文，避免回答不全或凭空补全。
7. “总结/梳理/汇总/列举”类问题会自动识别，并把命中文件的全部相关片段按来源补齐后（上限 `SUMMARY_RETRIEVE_LIMIT`）作答；总结/梳理类先概括核心要点、控制篇幅，避免逐文件铺开全部细项，“有哪些/列举”类只列主要条目并保持简短，只有明确要求“完整列出/全部条目”时才逐条列全；多文档总结/梳理时每个要点后标注（《文件名》）来源。
8. 多份文件同时命中时，会要求按文件分开作答，禁止把不同文件的条目混成一份清单；多问句检索按查询轮转合并，避免某个文件被其他文件挤掉。
9. 需要大段作答时先概括核心要点、尽量简练，但概括只能依据知识库内容，不得添加知识库之外的任何信息。
10. 来源只列出命中的文档名（去重），不显示页码。
11. 不知道时返回委婉未答，不显示来源，也不会要求你上传或补充文档。
12. 结构化解读/报告类问题使用独立提示词：只能填写知识库中明确写出的信息，没有依据的小节省略，禁止编造，禁止出现“知识库未提及/缺失”等评价知识库完整性的表述；每个要点标注（《文件名》）来源；整篇无依据时仍返回委婉未答。
13. 多轮对话仍保持严格 grounding：对话历史只用于理解指代与承接，不能作为知识库之外的新事实来源；承接问题会先把“它/它们/这个/该政策/上述内容”等指代词替换成具体话题（例如“数字孪生”），同一条消息里抛出多个问题时也会按句切分解析（如“数字孪生是什么？园区对它有什么期望吗？”），再改写为独立查询检索；未命中新内容时只允许沿用历史回答中已给出的信息，历史本身是委婉未答时仍返回委婉未答，未知问题不显示来源、不提供下载按钮，导出 PDF 时也会整组过滤。
14. 回答措辞面向普通用户：不在回答中提及“知识库/库内/知识库内容”等后台术语，需要说明依据时使用“根据我的理解”“从已有资料看”“据了解”等委婉表达；系统还会对模型输出做二次清洗，并保护《书名号》里的正式文件名。
15. 默认苏州/江苏语境：未点名外地、未要求横向比较时，检索范围限制到本地文档（国家/江苏/苏州/园区 + “其他地区政策”目录中确认的江苏/苏州文档）；“其他地区政策”目录中混放的江苏/苏州文档按“文件名 + 内容”双重判断保留。
16. 未知回答会追加“需要我帮你联网搜索相关的答案吗？”；只有用户同意（回复“可以/好的/搜索”，或点击网页“联网搜索”按钮）才执行联网搜索。联网答案固定带“> 以下内容来自联网搜索，并非官方文件内容，仅供参考，请谨慎辨别。”，`web=true` 且 sources 为空；搜索失败时返回“我尝试了联网搜索，但没有找到可靠的相关内容。你可以换个问法再问一次。”

常用参数可在 `.env` 中调整：`TOP_K`（返回片段数）、`SCORE_THRESHOLD`（相似度阈值，默认 0.05）、`CHUNK_SIZE` / `CHUNK_OVERLAP`（切块大小）、`RETRIEVE_LIMIT`（多问句检索合并后的片段上限）。总结/梳理类问题额外使用 `SUMMARY_RETRIEVE_LIMIT`（默认 200）、`SUMMARY_FULL_SOURCE_MAX`（默认 120）和 `SUMMARY_SEED_LIMIT`（默认 120）控制上下文补全与种子检索规模。本地向量模型（bge-small-zh）的相似度分数普遍偏低，所以阈值默认很低；如果回答经常被误判为委婉未答说明，再把 `SCORE_THRESHOLD` 调低；如果经常给出无关内容，则调高。检索采用“BM25 关键词 + 向量相似度”混合方式，中文用 jieba 分词；切块会识别“第一章”“三、”“（一）”等章节标题并保留标题上下文，适合政策法规类文档；普通命中优先于章节补漏，避免泛化词把真正相关的短文档挤出结果。每次提问还会用模型生成多个检索问法，合并后再作答，降低“换个说法就查不到”的概率。

## 常见问题

- PDF 是扫描件或 JPG/PNG 图片：现在会自动用本地 RapidOCR 识别文字，结果按页缓存，超大扫描件自动并行识别，长图自动分条带识别；如不想用 OCR，可在 `.env` 里设 `PDF_OCR_ENABLED=0`。超长扫描 PDF（如数百页）逐页识别较慢，可在 `.env` 里把 `PDF_OCR_DPI` 调到 100 左右提速。
- PDF 加密或报读取失败：先解锁 PDF，命令行会跳过无法读取的文件并打印原因。
- `.doc`/`.ppt`/`.wps` 读不出来：读取依赖本机 Microsoft Office 或 WPS 的 COM 接口；机器上装了 Office/WPS 会自动使用，未安装或运行环境没有桌面会话时，`.doc`/`.wps` 会回退到内置 OLE 解析、`.ppt` 会回退到文本扫描，正文以 Office 转换结果为准。
- 追加文档后答案重复：向量库按文件名去重；同名文件更新后请用 `--rebuild` 重建。
- 更换向量库或换模型服务：直接改 `.env`，然后 `.\.venv\Scripts\python.exe ingest_pdfs.py --rebuild`。
- 为什么回答不提其他地区政策？：默认以苏州/江苏（含园区）为主要语境；需要横向比较时直接问，例如“苏州和上海有什么区别”，或点名外地地区，例如“上海市数据条例有哪些规定”，才会引入外地文档。
- 遇到“不知道”会自动联网搜索吗？：不会自动联网。未答时会先问“需要我帮你联网搜索相关的答案吗？”，你回复“可以/好的/搜索”或点击网页里的“联网搜索”按钮后才会联网；联网答案会带“联网搜索”徽标和“来自联网搜索、并非官方文件内容、仅供参考、请谨慎辨别”的声明。
- 网页打开要求输入密码？：这是内部 demo 版的密码门，密码与使用规则见“Demo 试用版”小节；日常本地开发把 `.env` 的 `DEMO_PASSWORD` 留空即可关闭密码门。
